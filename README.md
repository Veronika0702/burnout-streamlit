# Прогноз професійного вигорання (Streamlit)

Веб-застосунок до лабораторної роботи № 3 з дисципліни «Інновації на основі штучного інтелекту».
Використовує багатошарову нейронну мережу з лабораторної роботи № 1, яка прогнозує рівень професійного
вигорання (`burnout_score`) працівника, що працює з дому.

## Вміст репозиторію

| Файл | Призначення |
|---|---|
| `app.py` | Streamlit-застосунок |
| `burnout_model.keras` | навчена нейронна мережа (ЛР1) |
| `preprocessor.pkl` | конвеєр попередньої обробки (StandardScaler + OneHotEncoder) |
| `requirements.txt` | залежності для Streamlit Community Cloud |

## Можливості

- введення показників робочого дня (тип дня, робочі години, екранний час, зустрічі, виконані задачі);
- готові приклади працівників;
- прогноз `burnout_score` і категорії ризику (низький / середній / високий) з рекомендацією;
- графік залежності прогнозу від обраного показника;
- перегляд ознак, переданих у модель, до і після масштабування.

## Локальний запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Параметри можна передати через URL, наприклад:
`?work_hours=11.2&screen_time_hours=14.5&meetings_count=7&task_completion_rate=45&day_type=Weekday`
